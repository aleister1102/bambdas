# Bambdas

This repository contains a collection of Bambdas (Burp Suite custom scripts) for various tasks such as custom actions, scan checks, view filters, and custom columns.

## Contents

- **Custom Actions**: Scripts that perform actions on selected HTTP requests/responses (e.g., injecting payloads, probing for race conditions).
- **Custom Columns**: Scripts that add custom columns to Burp's tables based on request/response data.
- **Scan Checks**: Custom passive or active scan checks.
- **View Filters**: Filters to show/hide items in Burp's tables based on specific criteria.

## Usage

Load these scripts into Burp Suite's Bambda interface corresponding to their type (e.g., HTTP Proxy > History > Filter, or Repeater > Custom Action).
